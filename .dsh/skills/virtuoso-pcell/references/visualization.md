# 出图配方：把 PCell 的绘制逻辑讲清楚，而不是画得像

> 目标有两个，别混：**(A) 自查**——判断几何对不对；**(B) 讲解**——让人看懂「为什么这样画」。
> 两者都要出图，但**判图先判数**：像素级的遮挡/配色会把真 bug 藏起来（失败案例 §7、§8）。

## 1. 三条铁律

1. **层序由下往上画**：TM1 underpass → TM2 主金属 → via。反了的话 TM2 会把 X 交叉整块盖住，
   图上只剩「一面旗子」，很容易误判成 underpass 画错。
2. **不要用 alpha 叠层**。半透明叠出来的紫色分不清哪层在上面。用不透明填充 + 描边色区分层。
3. **只画真实存在的半环**。用一整圈闭合多边形当「上下文」会填上本不该有金属的换圈缺口，
   把交叉区彻底糊掉。上下文用真实 `run` 折线 + 细描边。

## 2. 像素尺寸要反算

- 先定 `µm_per_px`（或 `px_per_µm`），再用**几何量**反算像素：`px = µm * s`。
  历史 bug 是 `side = max(cut, min_px/fig.k)` 把两套单位混在一起，via 只剩 1.7 px，
  肉眼看不见，于是被误判成「没画 via」。
- 自检：`cut / µm_per_px` 应落在 3–6 px；via 至少 4 px 才看得见。
  本仓库默认 `cut=0.5`、`via_span=6.5`，画 6 px 宽的方块即可。
- 自检：图上所有多边形面积之和 ≈ 内核多边形面积之和（差 >1% 就是画错了，不是几何错了）。

## 3. 一张合格的解剖图至少标五样

1. 比例尺（µm，画 10 µm 或 20 µm 的 bar）
2. `x = 0` 中轴线（X 交叉的交点恒在这条线上，画出来才能验证 e 的推导）
3. 圈号 k=0,1,2…（标在每圈 45° 斜边上，而不是直边）
4. via 位置（用方块，别用点；要能看出 span 覆盖多宽；默认画成 7 个 cut 的阵列）
5. 端口 p01/p02（箭头 + 名字 + 坐标），可选 bbox 虚线框

顺带把派生量印在标题行（`p / xj / e / a0`），读者能对着图找点。

## 4. 现成实现：`scripts/draw_anatomy.py`

```bash
python scripts/dump_geo.py -o geo.json          # 从内核导几何（自动补 w/s/n/ct）
python scripts/draw_anatomy.py geo.json out.png # 三段式解剖图
```

它画的是「一条臂 + 中心桥 + 差分引线」的三面板，正好对应讲解顺序：

| 面板 | 画什么 | 讲什么 |
|---|---|---|
| ① | TM1 + TM2 + via 按真实层序叠合 | 最终版图长什么样、层间怎么缝 |
| ② | 只画 TM1 | underpass 是两条 45° 斜带，不是「断掉的线」 |
| ③ | 只画 TM2 | 主金属是一条连续折线；换圈处的缺口正是另一臂跨层的位置 |

实现要点（改脚本时别踩）：

- 世界窗口从 `bbox` 推：`(bbox[0]-10, bbox[1]-8, bbox[2]+10, bbox[3]+14)`，
  上边多留 14 µm 给端口标注。写死窗口会在 n/尺寸变化时裁掉端口。
- 每个面板是独立 PIL 图层，**粘贴回主画布时所有坐标都要加面板偏移**
  （`PANEL_X/PANEL_Y`）；端口圆点与引线箭头忘了加偏移就会画到画布左上角。
- 标题与图注用 unicode `√ − ± ≈`，别用 `\u221a` 这类转义，PIL 中文/符号字体
  （`msyh.ttc`）能直接渲染。

## 5. 判图流程（图看着不对时）

1. 先分流：是**内核错**还是**出图错**？
2. 用坐标/面积/连通性判，不用像素判：`check_geometry.py geo.json` 先跑一遍。
3. 图与数矛盾时，**信数**。失败案例 §7 就是图错了、几何是对的，白改了一轮 underpass。
4. 只有在数一致的前提下，才用图去解释「为什么这样画」。

## 6. 给用户讲绘制逻辑的顺序（实测有效）

```
参数 → 派生量（p / a0 / b0 / c0 / xj / e / xe）→ 单圈 6 点 → 一圈半环
→ 两圈之间怎么交替 + 为什么必须换层 → X 交叉与 e 的推导 → via 为什么落在这里
→ 整条臂（N 圈一条线）→ 两条臂 + 桥 + 引线 → 最终叠层
```

每一步都用**具体数字**（rx=80, ry=60, w=8, s=3 → p=11, a0=76, b0=56, c0=32.804,
e=2.8995, xe=8.3995），不要只说公式。用户能对着数字在上图里找到那个点，才算讲清楚。
